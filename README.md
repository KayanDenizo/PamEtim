## Conteúdo

- App Android com tela de login, tela principal e tela "Sobre"
- Passo a passo para criar um app (`Passos para criar um APP.txt`): layout, IDs, `findViewById` e ViewBinding

## Como rodar

1. Abra o projeto no **Android Studio**
2. Aguarde a sincronização do Gradle
3. Rode em um emulador ou em um celular com depuração USB ativada
